# Security policy

## Supported versions

Security fixes are applied to the current `main` branch until versioned release
support is published.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security advisory flow for this repository and include affected revision,
deployment assumptions, reproduction steps, and impact. Maintainers will
acknowledge a complete report as soon as practical, validate it, and coordinate
remediation and disclosure.

For deployment boundaries and known limitations, read
[`docs/security/threat-model.md`](docs/security/threat-model.md).
