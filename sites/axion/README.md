# Axion public Site

This directory contains the static presentation Site deployed through ChatGPT Sites.

- Production address: `https://axion-vector-search.perkyaisle4.chatgpt.site`
- Hosting manifest: `.openai/hosting.json`
- Static output: `dist/`
- Operational console source: `../../apps/web/`

The public Site presents the release, evidence, architecture, and deployment paths without requiring a live Axion API. The operational console remains part of the self-hosted Compose and Kubernetes deployments.
